IMPORTANT: Do this in Phase 1 (frontend-only) first using mock data, but structure the code so it’s easy to add a backend later (Phase 2).

id, name, location, status, type (rent/buy), startingPrice, bedrooms, sizeSqft, images[], description

	•	Subtle hover effects and smooth transitions
	•	Keep it premium: neutral palette (white/gray/beige) with one accent color
